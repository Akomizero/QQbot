# P2 修复及视频故障核对

日期：2026-10-21（Asia/Shanghai）。延续管理员此前授权的P0验证，使用隔离模拟和少量真实模型调用，不向群聊发新的测试回复。

## 故障结论

一次已核对的请求诊断 在北京时间04:36:22–04:36:59记录6次代理连接 `ECONNRESET`，未收到模型HTTP响应。这是模型连接失败，不能据此断言B站视频读取器失效。

从授权群最近消息中仅定位该诊断对应的视频引用，没有导出聊天全文。再次读取同一公开视频成功，取得325字左右字幕和6张关键画面；以这些实际素材为输入、关闭私人记忆/知识/搜索/角色识别，在独立源码副本调用当前模型成功生成观后感，约10.7秒。没有把这条检查回复发到QQ。

最小连接对比中代理路由取得HTTP200（32个输出token触发length且无文字，不算完整回答成功），直连出现ECONNRESET。没有更改代理、接口、型号或密钥，也没有自动切换直连。单次成功不能证明间歇线路故障已经永久解决。

## 修复范围

- 普通回复的每个模型步骤共用最多2次HTTP请求（首次加1次补试）；关闭补试则仅1次。传输层不再与回答层乘出6次请求。
- 空答复/截断补试与连接/HTTP/正文错误补试共用同一额度，混合错误也不能重新获得次数；两次请求和等待共用60秒截止信号。
- 诊断中的次数连续显示1、2；页面说明实际额度、等待和独立工具/角色/后台任务的边界。后台独立任务仍有自身策略，不声称一次群回复所有步骤合计只有2个HTTP请求。
- 表情拒绝解析供候选积累和模型选图共用，支持“这个表情我不想再看到”“这张表情别再发了”“某某表情我不喜欢”等前后语序，避开明确的双重否定和无关分句。
- 有具体名称或引用库存表情时保存本群候选；仅说“这个”且没有可确认目标时不编造长期禁用对象，但本次回复不给模型提供选图工具。
- 视频材料读取成功后记录固定 `VIDEO_MATERIAL_READY` 阶段（无字幕、URL或图片）；模型随后失败会提示“视频素材已经读到，但生成回复时遇到问题”，与真正的视频读取失败分开。
