日期：2026-10-22（Asia/Shanghai）。

## 实际数据

只读检查发现两个授权群各有0条角色纠正候选，旧通用角色参考有1条「鸣潮·达妮娅」，自动学习、识图、角色辨认和搜索开关均开启。原页面选中群后仅显示该群条目，导致已生效的通用参考不可见。没有把空列表解释成学习成功，也没有创建假候选。

## 修正

- 本群列表同时展示该群条目和已启用的通用管理员参考，分别标记范围。统计显示「本群0条，另有通用参考1条」，不合并任何其他群的资料。
- 通用条目在本群视图仅可查看；点击「管理通用参考」切换到通用范围后才能编辑，沿用该范围修订号。其他群条目不会混入本群。
- 学习状态在本机持久化，记录每群最近一次处理阶段与时间，覆盖读图失败、内容检查拒绝或不可用、提取失败、没有明确纠正、图片不唯一、预览/指纹失败、保存失败和取消。原始聊天、图片、姓名标注、密钥及异常原文不写入这个状态文件。
- 已排队或处理中的状态遇服务重启显示「上次学习被服务重启中断」，不冒充完成或无限停留在排队。状态记录失败不会替代候选保存结果。
- 来源群仍需明确单图关联和角色名；候选仍需可靠正文及参考画面核对后才能自动采用，不因页面空而降低核实要求。既有通用参考继续标注为管理员资料，并非新完成的官方核验。

## 检查范围

修改文件语法与静态检查、重启后只读管理页面检查。没有新增或运行测试、没有调用模型验证新纠正、没有历史自动补录。新状态只能解释修正后的处理，不能倒推出旧请求失败原因；真实角色纠正落库仍需使用观察。
