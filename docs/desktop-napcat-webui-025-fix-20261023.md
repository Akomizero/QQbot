# NapCat 网页入口修复（0.2.5）

## 原因

0.2.4 在 WebView2 内请求了根路径 `/qq_login` 或 `/web_login`，本机 NapCat 返回 HTTP 404。NapCat 本身正常监听，登录状态接口和会话鉴权正常。

该版本前端设置了 `/webui/` basename。本机读取 `/webui/` 返回 HTTP 200 和完整 HTML；直接请求 `/webui/qq_login` 虽为 HTTP 200，却返回 50 字节 JSON 错误。因此统一打开 `/webui/`，由 NapCat 原生前端在加载后判断是否转入扫码登录或仪表盘。

## 修复

- 初始化和刷新都进入实际 HTML 入口 `/webui/`。
- 导航完成时检查 HTTP 状态码，避免把 404 错误页标记为加载成功；本地日志只记录状态码和错误枚举。
- 主窗口 F5/Ctrl+R 在 QQ 登录标签刷新 NapCat，其他标签继续刷新管理面板。
- 人设、bot 源码、QQ 登录文件和密钥均未修改。

## 证据和范围

本轮读取了正在运行的 NapCat 本机 HTTP 路由响应及前端路由配置，未运行自动化测试，未回放真实扫码。
已离线编译桌面程序 0.2.5。安装后需正常关闭旧版桌面窗口，再从桌面快捷方式启动新版；当前窗口不能热更新。
