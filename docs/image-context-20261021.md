# 分条发图与图片追问

更新：2026-10-21（Asia/Shanghai）。所有已授权群默认适用，使用现有“图片识别”开关；无须逐群添加规则。

## 支持的对话

- 同一成员先发图片，3分钟内再 @bot 说“如何评价”“看看这个图片”，附带最近一次图片消息（最多2张）供模型理解。
- 开启自然接话时，bot已在与该成员对话，继续说“这个图片”“这个GIF”可关联前图；45秒内直接补发图片也可接话。仍受原有跟进次数与对话对象判断限制。
- @bot并引用图片消息时，优先读取明确引用的同群图片，最长15分钟。不用另一个最近图片替代无效引用。
- 进程重启后，可按需读取本群最近20条消息，恢复3分钟内、同一发送者的图片关联。

图片来源以平台群号、作者、消息号标注给模型。图中的虚构角色不会仅因“发给你看”就被视为bot本人。GIF当前仍只提供首帧，不能根据单帧编造完整动作。

## 范围与存储

默认关联仅限当前群、当前发送者；@别人的消息不会作为发给bot的图片。明确引用可以选择同群其他成员的图。最多128群、每群20条引用，只在内存短暂保存QQ文件标识，不存原图或消息正文；需要回答时才通过原有get_image校验流程读取。表情主动收藏继续使用独立的现有开关和审核流程。

停用识图、修改分群人设、清除成员印象时清理关联；排队任务执行前复查有效期和清除时间，不使用已经过期或已忘记的来源。群白名单与发言间隔继续生效。

## 验证

108项隔离回归全部通过，其中新增13项图片关联检查：多个群均可用、同群同作者、跨群/跨人隔离、有效期、人设清除时间、普通文本与@他人、重启后读取近期历史、引用优先、非法文件标识、排队重查、实际handler将前图附入模型并发送回复、无@追问、纯图片跟进、关闭识图。这里的模型与OneBot为隔离替身，不声称等同真实QQ入站完整验收。

另取授权群中实际“先发GIF、再问如何评价”的历史消息，按原消息时间重建关联，真实get_image读取一张图并通过当前模型生成52字符答复，未再声称图片缺失；专用出口取得HTTP200。该回放没有向QQ群发送消息，原图和回复正文未写入验证报告。前端已确认识图与自然接话均开启，并显示新功能说明。
