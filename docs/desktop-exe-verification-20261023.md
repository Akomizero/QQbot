## 已解决的原型故障

1. PowerShell5.1中文源需要UTF-8 BOM，构建/安装/控制脚本已处理。
2. 状态轮询占用期间关窗不能直接退回；先停轮询并等待当前动作结束，再执行退出。
3. 外层Windows Job可能拒绝接纳旧进程或控制器；保留核实过的身份回执，停止流程继续执行，并明确显示回退，不能因Job保护未建立而漏停后台。
4. 后台子进程可能继承控制器管道句柄；只读取JSON行和等待控制器PID退出，不等待所有子进程释放管道EOF。
5. WebView2需在窗口中实际创建控件；版本和前端资源以最终构建摘要为准。

## 尚未实测的边界

- 真实专用QQ的可见扫码/登录、重启NapCat、群消息收发，本轮均未执行。代码使用可见启动和仅专用路径恢复，不能把隔离Node验收当成QQ真实验收。
- 原真实bot保留旧进程；新健康、版本摘要和退出管道在用户明确接管并重启bot后加载。
- 桌面原型仍使用已有项目和Node/NapCat等外置依赖；不是全新机器的完整运行环境安装包。
- 密钥/记忆仍在本机原项目目录。要迁移至新的统一用户数据目录，需要另做有备份的显式迁移；本轮没有移动真实数据。
