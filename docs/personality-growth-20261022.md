# 性格随相处成长

日期：2026-10-22（Asia/Shanghai）。入口：管理页 → 分群人设 → 选择群 → 性格随相处成长（本群）。

参考 [inner-life](https://github.com/DKistenev/agent-inner-life/blob/main/skills/inner-life/SKILL.md) 的带日期反思与短摘要延续方式，适配肥鱼现有的群聊提炼和回复流程。本功能直接进入 bot，不依赖开发助手每次在场。没有照搬跨会话全局摘要或自由“梦境”。

## 成长内容

- 每个授权群默认启用，独立保存表达习惯。成长仅包括闲聊篇幅、接玩笑的方式、温和/活泼的节奏、表情使用倾向与分享时的自然表达；值来自程序限定的描述，不接受模型任意改写提示词。
- 管理员设置的身份、形象、核心性格和权限继续作为基础。事实核实、当前具体任务、成员个人偏好和内容检查优先；不会因成长扩大白名单、主动发送次数、搜索或分享权限。
- 对有意义的真实互动反馈做结构化反思。例如反复希望回复短一些，或反复肯定bot的玩笑。普通提问、转述、引用他人、单纯夸图片和不明确的笑声，不应成为性格依据。模型先判断，程序再校验消息资格、原文反馈词、作者、时间和去重指纹；仍可能漏掉隐含反馈或误读讽刺，不能保证社交理解完全准确。

## 逐渐形成

1. 群消息必须实际发给bot，未引用其他群友，经过现有非敏感内容检查。暂停个人记忆积累或“忘记我”的成员不再贡献成长反馈。
2. 在原知识/成员对话整理调用中，追加有限的成长反馈分类，不另开专用“内心独白”请求。若只保留成长开关，则由同一整理器按需处理反馈，仍会使用当前配置的模型；不是零调用成本。
3. 同一个方向至少3条不同消息、2种不同表达，跨度至少30分钟，并来自至少2位成员或跨2个自然日（Asia/Shanghai），才有资格自动采用。单次反馈先观察，无需管理员逐条确认。
4. 每次只调整一个方向，至少间隔6小时；这段时间继续积累，不是每日额度。相反方向都有近期充分证据时保留观察，不来回翻转；新反馈持续收敛后可以改变旧习惯。原始反馈仅在短期内存缓冲，重启不恢复聊天全文；已经提炼的依据持久化。
5. 新的组织回复读取本群已形成习惯，并以简短的固定描述加入角色上下文。普通回复、自然接话、主动聊天和已授权B站分享的表达会使用；具体任务的长度和格式要求仍优先。已生成的排队文本不会被重新改写。
6. 后台每5分钟检查一次已积累的反馈，满足间隔和证据时可继续采用下一项，不为此额外调用模型或向群发送进度。

## 管理和撤回

- 分别控制“在回复中体现习惯”和“继续积累反馈”。暂停积累保留已有习惯；停用效果后暂不注入成长描述。开关按群立即保存，对下一次组织回复生效。
- 页面显示已形成习惯、来源数量、开始时间、待观察反馈、带日期的成长/设置/撤回记录，以及短期反馈缓冲、模型整理或保存异常的状态。没有发生调整时保持空白，不编写虚构心情或经历，不生成情绪分数。
- 可以逐次撤回最近仍生效的调整，恢复其前一版；被撤回方向暂停自动重学，旧证据不能立即把它改回去。可以明确允许从新互动重新学习撤回方向。
- 暂停、停用或撤回会递增修订代数，迟到的模型提炼不能使用旧任务写回。改变核心身份、人设或基础表达风格后旧成长不再套用，后台清理旧方向，重新从新互动形成；旧调整不能跨人设恢复。只改群备注、呼唤词或补充群记忆不清空已有成长。
- “忘记我”同时移除对应成员的成长贡献，来源不足的习惯停用，并清理可含这些贡献的撤回快照，防止恢复操作把它们带回。保留的成长日志只是匿名、汇总后的行为调整描述，不含聊天原文。

## 数据与边界

`data/personality-growth.json`保存按群开关、固定方向、来源指纹、分群匿名贡献标识、时间、最近30次调整快照与60条汇总日志；管理页不回传成员QQ、原文或来源指纹。资料随现有data目录进入私有备份，不发布真实成长记录到GitHub。总文件2MiB与128群为异常存储防护，不是每日学习配额。

这是基于互动的表达习惯成长，不是训练模型权重或让bot获得真实情绪。个人知识、网梗与成员档案仍由现有知识/成员模块保存，避免混入角色身份或跨群套用。

## 完成与证据范围

本轮完成源码/语法检查、部署和管理页只读查看；没有新增或运行测试，没有伪造反馈、回填旧聊天、强制触发提炼或发送QQ群测试消息。多轮真实反馈→自动形成→回复体现→撤回的完整效果与隐含反馈识别，仍需真实使用观察。初始页面开关已开启但习惯和日志为空，不能作为已发生性格成长的证据。
