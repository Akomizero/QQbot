# 后台重试与补发

## 已接入

临时模型/搜索/转发图片故障在向群友返回一次失败提示后，登记原消息指针。OneBot 连接有效时后台串行处理，最多三轮，等待间隔约 1、3、10 分钟；六小时过期。重启后继续未完成任务，但已开始的次数仍计入上限。

重新从原会话取原消息，并验证发送账号、群、成员、授权、人设修订与成员清除状态。原图片或转发引用按原请求时间重新定位；不拿重试时的新对话替代原问题。权限撤销、相关功能关闭或人设/成员状态变化时取消。

恢复成功后引用原消息，向原群/授权好友补发文字答复，不重复发送中间进度。磁盘只保存指针、时间、状态及错误类别；不保存完整聊天或图片链接。每条原消息有独占发送回执。已确认发送不会因为读回失败而再次发送，传输结果不确定时等待核对。

密钥拒绝、额度耗尽、明确拒绝处理、参数错误不作为临时网络故障无限重试。网页生图使用独立队列，不进入此重试通道，避免重复生成或消耗账户额度。

管理页“模型连接与回复参数 → 后台重试与自动补发”可只读查看数量，不触发发送。

## 验证范围

发送、引用、原目标限定、读回确认与手动恢复已实际使用；常驻队列已接入服务，进行了源码与语法检查。没有故意制造服务断线、撤权或进程崩溃来测试各故障分支，也未额外运行自动化测试。周期重试需要以之后真实临时故障的记录继续核实。
