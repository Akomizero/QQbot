# 需求与实现范围

更新：2026-10-21（Asia/Shanghai）。这是公开版清单；不附私人聊天、群号、人设全文或运行数据。“已实现”表示代码具备功能，不代表每个边界都通过QQ真实入站验收。

| 模块 | 已实现的范围 | 仍需补齐或持续验收 |
| --- | --- | --- |
| 模型 | 服务端凭据、可编辑接口与型号、视觉输入、有限重试、专用出口与备用节点、连接池、关联诊断、空答复分类 | 外部网络稳定性；当前供应商原生Google grounding能力未证实 |
| 搜索 | Tavily/Exa/B站备用链、按需工具调用 | 备用渠道不保证只搜国内；第三方搜索插件未集成 |
| 分群 | 白名单、分群人设/昵称/固定记忆、独立知识和偏好 | 多人对话的真实场景误接、漏接仍需持续观察 |
| 对话 | @及引用作者结构化传入、引用同群校验、昵称触发、10秒FIFO、主动参与与冷场暂停 | 自然对话对象判断仍有模型误差；重启丢弃内存发送队列 |
| 知识 | 本机检索、聊天提炼、候选确认/拒绝、来源指纹、修正候选、状态可见 | 按群+成员独立印象、明确自述、候选审核、忘记/暂停已实现；图片纠正不自动成为完整视觉角色档案 |
| 图片 | JPG/PNG/WebP/GIF读取与缩小、角色辨认步骤、简短感受、所有授权群分条发图关联与图片追问 | 所有角色的识别准确率；完整角色参考管理页未实现 |
| 表情 | 上传、自动学习、显式赠送、用途/避免场景、内容检查、token同图回复路径 | 模型审核有误判风险；token原图回发不受库存偏好控制 |
| 偏好 | 分群逐图/关键词禁用、反馈候选、管理员确认、近期去重、发送前复查 | 成员印象可保存娱乐偏好，库存发图禁用仍以群为作用域；关键词不等于识别所有图片内角色 |
| 内容 | 通用摘要、原页日期核对、来源尾注、详细分析、合并转发、图文分页 | 来源可靠性及实际客户端排版仍须按内容验收 |
| B站 | 字幕、受限ASR、有限关键画面与观后感 | 不是完整逐帧观看；站点限流、登录及字幕可用性影响结果 |
| 运维 | 本机管理认证、登录自启、异常恢复、保持唤醒、SHA-256备份 | 不能在真实休眠/关机时运行；备份恢复演练尚未完成 |
