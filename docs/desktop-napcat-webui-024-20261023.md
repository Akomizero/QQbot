# QQ 登录内嵌 NapCat WebUI（0.2.4）

## 需求与实现

“QQ 登录”默认显示本项目专用 NapCat 网页，提供原生快速登录、扫码和 NapCat 状态界面；增加“刷新 NapCat 网页”。原二维码展示保留在“备用二维码”标签。

顶部状态继续每 5 秒通过控制器检查 QQ 登录和 bot 健康回执、OneBot 授权连接，不以网页加载成功判定 bot 就绪。刷新网页不重启 QQ、不刷新 QQ 登录二维码。

## 接入边界

- WebUI 地址由控制器核对监听进程属于本项目专用 QQ 后提供，支持 NapCat 自动递增端口。
- 使用独立 WebView2 控件，与管理面板共用浏览器环境和退出保护。顶层导航只允许对应本机来源。
- 本机已有 WebUI 会话通过专用 `LoginWeb` 控制器动作传给窗口，注入对应来源的本地存储。原始 token 不进入地址、状态快照、分发包或日志；普通 Status 不返回会话凭据。
- 启用 WebUI 二次验证时显示原生 WebUI 登录页面，需用户完成验证；沿用控制器此时无法独立读取 QQ 登录态的现有限制，OneBot 状态仍显示在状态列表。
- 现有服务、人设、模型配置和群聊记忆未改动。

## 文件

- `desktop/NapCatPage.cs`：WebUI 控件、来源限制、会话接入。
- `desktop/Program.cs`：登录标签、共享浏览器退出管理、版本 0.2.4。
- `desktop/control.ps1`：已验证 WebUI 来源和独立的会话交付动作。
