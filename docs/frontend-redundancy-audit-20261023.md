## 容易误认为重复，但应保留的能力

- 默认人设与分群人设：前者服务私聊及未开启独立人设的群，后者覆盖特定群配置。
- 人设、表达风格、系统提示：都有实际注入，但自由文本容易重复填写或冲突。建议基础页只突出人设与风格，把系统提示放入高级设置，明确优先关系。
- 知识库、成员印象、视觉记忆、性格成长：分别记录群知识、某个成员、图片角色关联和 bot 自身习惯。可统一导航和选群体验，数据与控制开关应保留。
- 学习开关与使用开关：可以停止新增但继续使用存量，也可以暂停使用，不能简单合并。
- 自然接话与主动聊天：`src/main.js` 分别消费 `conversationFollowupEnabled` 与 `proactiveChatEnabled`，上下文衔接和主动判断并非同一行为。
- 模型请求补试与消息失败补发：处于不同处理阶段，不应只因名称类似删掉其中一个。
- 顶部状态卡与详情状态：属于概览和详情的有意重复，无需优先删除。
- Serper 与 Tavily：是替代服务选项，保留当前按选择显示字段即可。

## 建议处理顺序

1. 优先统一提炼任务文案、作用范围与进行中状态，避免用户误以为是两个独立任务。
2. 统一记忆维护入口与群选择体验，保留各类记忆独立编辑能力。
3. 将时间、骰子改为模板入口，将桌面低频排障操作收起。
4. 清除无用变量及重复筛选入口。

本次没有执行删除或合并；上述事项需按兼容现有配置的方式实现。
