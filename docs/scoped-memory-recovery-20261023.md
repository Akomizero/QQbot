本项修正[追加验收发现的退化](sticker-memory-integration-verification-20261023.md)，保留隐私保护；不恢复旧版无条件注入。固定记忆和成员事实的**条件召回路径已恢复**，旧数据未经授权仍不用于回复，不把“管理页能看到”当成“聊天能记住”。

## 使用与管理

| 内容 | 管理入口与授权 | 使用边界 |
| --- | --- | --- |
| 本群固定常识 | 分群人设→本群长期记忆→“允许在本群回复中使用其中的非敏感常识” | `memoryReplyEnabled` 默认 false；仅独立人设启用的来源群，不继承默认/其他群/私聊记忆 |
| 默认私聊常识 | 默认人设→“允许使用上述非敏感记忆的私聊账号” | `memoryReplyUserIds` 默认 []；只用于明确列出的账号私聊，绝不作为群 fallback；不会根据饲养员关系推断收件人 |
| 成员印象 | 成员编辑→每条“成员已同意：允许在来源群回复中使用此条非敏感印象” | `replyAllowed` 默认 false；逐条确认同意后设置，仅当前群当前成员的相关话题召回；授权公开范围是来源群，非私聊/跨群权限 |

成员授权由 `replyContentHash` 绑定具体正文；自动改写后原授权失效，候选/停用/拒绝/归档及成员停用不使用。新自动学习不自行设置授权。管理页显示失效授权为关闭，原数据保留。

账号、内部身份关系、权限、密钥和敏感私人资料不因勾选而进入常识；应用内部身份匹配继续只影响交流语气。过滤规则是保守关键词与已知资料检查，不能称为对任意语义或图片隐私的完整保证。文本可能因与其他受保护资料相似而被保守拦截。

## 实现路径

- `memory-reply-access.js` 定义正文可用性、授权范围、成员内容指纹。
- 配置/分群人设保存并校验授权；原记录默认关闭，无批量迁移或自动公开。
- `llm.js` 在可信调用上下文里选择本群/私聊授权记忆，仅为当前成员调用已授权印象筛选；输入最后清洗和模型结果保护使用相同作用域。
- 最终发送与图文渲染检查按实际目的群/私聊重新读取授权，不依赖模型声明；OneBot 在发送前重新检查，合并转发也按真实目的地检查。排队期间撤销后，旧生成文本不能继续发送。
- 后台学习/维护保留；可共享群常识与内部认证资料分开处理。授权不会成为模型指令或额外平台权限。
