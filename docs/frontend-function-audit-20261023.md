# 前端功能逐项核对与 0.2.6 优化（2026-10-23）

## 结论

管理前端与桌面壳均已具备实际处理逻辑，不是展示空壳。源码中共有 166 个表单/按钮类控件；44 个持久化聊天设置字段全部映射到管理页。管理页的 8 个功能页均有读写接口、状态回读和运行侧消费位置。

## 0.2.6 页面优化

- 增加 QQ 连接、模型密钥、搜索来源三张运行状态卡片，并可跳到对应设置。
- Serper 与 Tavily 根据当前选择只显示相关密钥输入，减少误填。
- 搜索来源卡片可直接展开“联网搜索来源”。
- 模型设置底部显示“已保存 / 有未保存修改”，保存期间禁用提交按钮，减少重复提交。
- 小屏幕将状态卡片改为单列，保留现有八页导航与折叠设置。
