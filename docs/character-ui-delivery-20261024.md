## 角色链路的改动

1. 第一轮识别不提供库存角色名、作品名。只有同一文件的标注能在后续阶段作为标注使用；近似指纹和其他图片的旧名字不再引导识别。
2. 每张图索引必须唯一、完整、范围正确并排序，覆盖九张图。已确认标注也不再跳过实际看图。识别缓存限五分钟，标注变更使缓存失效。
3. 发色、瞳色两条泛泛描述不支持确定姓名；具体特征按类别检查。新增明确枚举的结构化特征，兼容旧文本匹配，避免只因中文同义词写法就漏掉已看到的细节。它仍依赖模型观察，不能证明模型看对或消除幻觉。
4. 明确问身份时可做第二轮无上一轮答案的独立复看。两轮一致只表示同一服务的视觉一致性，不是独立来源、更不是官方核实。有效复看不支持/不同意第一猜测时弃答或提示冲突；未取得复看结果时维持候选，不升级。
5. 同图临时标注保留“来源群、未核实”属性，不因第二轮一致自动升级；冲突及已撤回标注不复活。同群可有限参考，不跨图片或群扩散。
6. 普通看图回复使用语义身份提及审核，保留没有姓名的真实动作描述。有依据且图片归属明确的姓名保留；候选加不确定限定；临时标注加未核实说明；无支持身份泛称化。按名字的**出现位置**处理，不用全局替换误伤另一张图中的同名角色；重复/歧义归属保守处理。审核不可用时依据结构化动作简短回应，不把“拥抱”编成“笑”。此审核同样依赖模型，并非形式化语义保证。
7. “这是谁，详细介绍/查证剧情”等复合请求不再被末尾身份模板覆盖。保留相关详细回应与来源；不能将未知图片套入任意候选的剧情。
8. 转发图片批次同时取得描述和角色观察，每批增一次文字身份审核，保留原图片编号；重复或缺失编号不冒充读完。观察及受控身份状态传给最终回复审核。没有重新上传真实39张群图，也没有对那条真实事件作全量复现；新增文字审核可能增加阅读耗时。
9. 补充“刚才那张是谁”等图片追问识别；显式引用仍优先、限定群与时效，不借用另一张新图。
