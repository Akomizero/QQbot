# 角色纠正与知识积累

日期：2026-10-22（Asia/Shanghai）。

## 角色视觉记忆

- 新增「角色记忆」管理页，按群显示待确认、已确认、停用和拒绝的标注；支持搜索、编辑、确认、停用、拒绝和删除。
- 群友附一张图片并明确纠正虚构角色名，或本人发图后3分钟内补充说明，可以产生候选。明确引用同群图片支持15分钟内的关联；也支持引用bot近期发送的已审核库存表情。不是任意翻查其他成员的图片，多图不明确时不自动绑定。
- 先复用图片内容检查，再提取用户实际说出的角色名和作品名、可见特征。作品未知时留空，管理员确认前需补充；不推断真人身份。
- 保存通过检查的240像素以内低清JPEG预览、处理后图像指纹、角色标注、来源时间与哈希。没有保存完整原图或完整聊天。GIF候选仅针对识图输入的首帧，不代表记住全部动态。
- 群友标注先作为候选，不因多人重复自动成为角色身份。按用户后续要求，先联网核对，证据充分后自动进入本群参考；不足或冲突时保留待核实，也可由管理员决定。相似指纹只提供候选，不保证识别同角色的不同新图。
- 旧角色参考会作为已有管理员确认参考读取，在「通用管理员参考」或其原群中管理。首次修改后写入新的视觉记忆文件，后续不从旧文件恢复已删除的条目。通用参考的作用范围明确显示为所有群。
- 已确认标注的编辑/停用/拒绝在下一次识图生效。拒绝与停用不会被同图同名的群友反馈自动重新启用。
- 确认同群同图的新标注时，旧的已确认标注会停用；本群的已确认同图标注优先于通用参考，不修改其他群。
- 独立学习开关默认开启，并受识图、角色辨认、授权群和群人设版本检查约束；后台处理不向QQ群发送进度消息或额外确认消息。

## 知识库增长少的已确认原因与修复

检查时知识库共6条，其中3条待确认；两个授权群的学习记录都达到旧版每日12次上限。后续日常对话仍可能增加成员印象，但知识提炼受到上限阻挡。

1. 移除知识提炼每日12次硬上限，保留每群至少5分钟合并处理、消息去重及隐私/来源校验。
2. 短期缓冲满时优先保留明确解释、教学和纠正，避免被普通闲聊全部挤掉。只保存提炼结果与来源指纹，原始聊天缓冲仍不跨重启持久化。
3. 状态分别记录新增/更新群知识、成员印象和知识保存时间；只保存成员印象时显示「本轮只更新成员印象」，不再宣称知识库增长。
4. 网梗、群内称呼与互动背景进入知识库；个人喜好和直接对话观察进入成员印象。没有可复用知识时允许没有新增，不填充虚假知识。

## 证据边界

本次完成源码与语法检查、部署以及管理页只读查看；没有新增或运行自动测试，没有伪造群友纠正、强制调用提炼或发送QQ群测试消息。角色纠正的真实入站→内容检查→候选→联网核对或管理员确认→后续识图效果，以及知识库后续实际增长，仍需由真实使用继续观察。旧版真实识图或提炼结果不能冒充新版端到端验收。

## 同日追加：先搜索核对，再决定是否采用

用户进一步明确不要求每条手动确认，游戏内容优先查维基百科。流程已调整：

1. 角色纠正通过图片内容检查并提取用户实际说出的名字后，先查中文维基百科，再补游戏Wiki与官方资料；沿用现有搜索服务和联网开关，关闭搜索时不私自联网。
2. 从限定的出版商官网和已列入来源范围的维基站点中，最多读取3个不同站点正文。搜索摘要、论坛和用户帖子不能作为核对通过的证据。同一百科的不同页面/不同语言版不能冒充两个独立站点。
3. 从实际页面取得与名字相关的静态参考图，对照原图。网页姓名与作品关系、正文中的逐字证据和至少两项独特画面特征必须共同成立。只有名字命中、相同发色、网站logo或泛游戏封面均不足以自动采用。
4. 自动采用要求至少一个限定官网正文，或两个不同的限定百科站点正文支持；引用必须能在实际正文中找到，并实际读到相应参考图。缺来源、缺参考图、搜索失败、身份冲突均保留候选，不假装核实成功。
5. 页面显示联网核对结果、实际来源、支持原文和核对时间，区分联网自动采用与管理员标注。与已有同图身份冲突时不自动覆盖。自动核对仍依赖来源质量与模型视觉判断，不能保证绝不出错。
6. 普通知识提炼新增内容类别：只有本群梗义和互动约定可以按原规则自动启用；角色、出处及其他事实性说法均需核实，不因群友多人复述自动升级。视觉回复也不得因群友说得肯定或知识库里写着一个名字就顺从认人。

追加部分完成源码/语法检查和页面只读查看，未新增/运行测试，未虚构纠正或实际触发一次自动核对；首次真实搜索、来源读取、参考图比较到自动采用仍待真实使用观察。

管理员修改身份或视觉特征后会清除旧联网核对结论，显示为管理员标注，避免旧证据被套用到新身份。
