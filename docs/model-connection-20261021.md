# 模型连接与工具后续回复故障核对

日期：2026-10-21（Asia/Shanghai）。仅保存故障类别、次数及验证结论，不发布群聊正文、群号、模型地址或密钥。

## 观察与调整

早间检查中，多个群回复出现 ECONNRESET；部分请求第一次已取得 HTTP200 和工具调用，随后生成最终答复时断开，另一些在收到 HTTP 响应前断开。不能将这些错误统一归因于视频读取失败。

Node 与 curl 均曾在通过本机代理按域名连接时失败；同期使用 DNS 当前解析的 IPv4 地址建立 CONNECT 隧道、仍以原域名进行 TLS 验证时，两个地址均取得 HTTP200。之后域名路线也恢复，因此这组证据提示间歇性代理连接/解析/路由问题，尚不能断言某一个代理节点、IPv6 或上游模型是唯一根因。

模型传输现使用当前系统解析的 IPv4 地址建立代理隧道，CONNECT目标和代理Host保持一致；HTTPS请求的Host、SNI、证书身份继续使用配置的原域名。未硬编码IP、未关闭证书校验、未改用户全局代理、接口、模型或密钥。DNS结果短暂缓存60秒，原有补试在可用地址间轮换；解析失败回退原代理方式。普通单步请求仍最多2次，共享60秒截止时间。

管理页显示“代理 IPv4”；诊断增加固定工具名的开始/结果已附加阶段，不保存工具参数和结果正文。可区分工具处理与后续模型失败。
