# 按群成员积累长期印象

日期：2026-10-21（Asia/Shanghai）。入口：管理页 → 成员印象（`#members`）。

## 后续更新

日常对话积累、无成员每日次数额度、证据合并、自动修正与过期维护已实现，见[日常对话与自动维护](member-dialogue-learning-20261021.md)。下文保留早间实现和验证历史，不是现行积累条件。

## 早间行为（历史）

- 按可信OneBot群号与发送者QQ号持久化；同名不同QQ、同一人在不同群分别维护，不用于私聊。显示昵称仅作界面标签。
- 只积累主动自述的非敏感娱乐偏好、兴趣、称呼和互动习惯。明确“记住”的自述可自动启用，普通自述先待确认；不从提问、猜测、转述或带引用的消息建立成员印象。
- 自动启用的正文来自已过滤的实际自述片段，而非模型补充的细节；模型帮助提取主题和原文关键词。证据作者与成员编号由程序校验，模型不能指定QQ号或跨成员合并证据。
- 与群知识提炼共用一次模型请求、每群5分钟间隔和每天12次额度，不逐条调用模型。明确自述优先约5秒安排，但仍受冷却和额度限制。重启不恢复原始聊天缓冲；从部署后的新发言开始，不回填历史聊天。
- 管理页可按群选择、搜索昵称/QQ、查看候选和来源指纹、编辑、确认/拒绝、停用召回、暂停个人积累、删除条目或清除整个人的印象。每人最多20条，每群最多200人，总量2MiB。修改后点击“保存成员”生效。
- 已确认知识有不同说法时生成修正候选，确认新版本后停用旧版本；删除/拒绝保留主题级阻止标记，不自动重新学回相同主题。
- 群友在本群@bot后说“忘记我”会立即清除自己的长期印象并暂停积累；“继续记住我”恢复积累，旧印象不会恢复。不能通过正文指定他人的QQ号清除他人资料。

## 数据与清除

`data/member-impressions.json`保存提炼结果、最小成员标识、显示昵称、来源指纹与时间、启用状态和修订代数。不保存聊天全文或图片，不纳入Git发布，已纳入本机数据备份。

清除后保留最小QQ号、暂停及代数标记以阻止后台旧任务写回；清空对应学习缓冲及本群短期话轮，后续历史上下文不导入清除前的内容。旧排队模型回复在实际发送前重新校验代数，清除后不会再发出基于旧印象的回复。此功能不操作QQ平台已有聊天记录。

仅召回当前群、当前发送者已经启用且与话题相关的印象（最多4条）；不会把群知识中的匿名成员偏好当成当前发言者身份，也不把印象当作权限或已核实事实。

## 验证

- 本机隔离81/81通过（含随后增加的4项模型连接回归），包含原P0/P2及新成员归属、跨群/跨成员隔离、同名分离、候选审核、持久化、修改冲突、删除不复活、暂停/停用、忘记与恢复、旧任务/旧排队回复拦截、历史话轮截断、单次共享提炼和管理API认证/作用域。
- 使用虚构成员资料调用真实模型：有效自述提取1条，当前成员召回、其他成员不召回、清除后不召回均通过。没有向QQ发送这次检查结果，没有将虚构资料写入正式印象库。
- 本轮仍未使用第二个QQ账号完成真实群友入站验收。

运行 `npm run test:p0` 可复现隔离检查，报告位于`.local/p0-check-metadata.json`。真实模型检查记录位于`.local/member-live-check-metadata-20261021.json`。
