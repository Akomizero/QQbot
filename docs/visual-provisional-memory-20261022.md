# 角色视觉记忆：本群临时标注与冲突复审

**日期：** 2026-10-22（Asia/Shanghai）<br>
**交付阶段：** 本地实现与集成审阅；尚未重启加载、发布或完成真实 QQ 入站验收。

## 行为

群友明确纠正虚构角色，并关联到可追溯的单张图片时，通过既有基本图片内容检查后保存 `provisional`。联网搜索成功不是入库前提；搜索关闭、故障或可靠资料不足，临时标注仍可保留并有限使用。后台核对可补充证据，不能把群友说法无条件升级为通用事实。

同图指纹可参考本群先前标注，但明确它是群内未核实说法。不同图片中的名字、作品和特征只作弱提示，必须与当前画面相符；不能因为群内记忆而强行指定身份。只记虚构角色，不记真人身份；多张图片关联不清楚时不自动绑定，既有图片内容检查和群隔离保持生效，标注内容不作为模型指令。

## 状态与撤回

| 状态 | 识图用途 | 管理方式 |
| --- | --- | --- |
| `provisional` 临时标注 | 仅来源群；同图参考、异图弱提示，仍未核实 | 可选定确认、暂停复审、撤回、拒绝、停用、删除 |
| `disputed` 待复审 | 暂停自动使用；同图有争议时不能绕回通用参考继续套用 | 查看双方关联条目和证据，选定一条临时/确认标注，或保持暂停 |
| `candidate` 旧候选 | 管理员撤回或来源条件不足的候选不使用；来源完整且未被管理员处理的旧候选按临时标注展示和使用 | 可审阅选定，或保留、拒绝、停用、删除 |
| `confirmed` 已启用参考 | 依据保留的管理员/联网核对属性使用；仍需结合画面 | 可撤回、暂停、拒绝、停用、删除 |
| `disabled` / `rejected` | 不使用 | 可保留供追溯，管理员可编辑重新选定或删除 |

同图出现不同角色/作品或可靠资料冲突时，保存双方证据与来源，不静默覆盖。管理员选定本群某条为临时或确认状态，同群同图其他标注停用并记录选定关系；通用原记录不改写，其他群不受影响。编辑沿用所属范围与版本校验，不提供把本群临时标注升级为通用记忆的操作。

兼容旧记录时不批量迁移数据：符合可追溯单图条件且没有管理员处理决定的旧候选，在读取时投影为 `provisional` 并标记 `legacyCandidate`。管理员撤回的候选不参与此兼容，不会因为旧候选兼容而重新启用。

管理页展示来源时间、消息/图片来源指纹、核对资料链接、冲突关联条目、选定历史。选择有冲突的条目时提示同群同图其他记录会停用。撤回使用将本群条目保留为不参与识图的旧候选；停用/拒绝不会删除证据；删除属于直接移除当前条目，不声称可在页面撤销删除。

## 当前服务与本地代码

前端以 `/api/visual-memory` 的 `workflow: "provisional-conflict-review-v1"` 区分新版服务。缺少标识时，页面提示运行中的服务仍是旧版，禁用新状态选定和保存，不把磁盘上新页面说明当作新版运行证据。通用参考若在本群因争议或已有本群选定结果而被屏蔽，页面单独标记，本群页面不能直接修改通用条目。

本轮保留真实用户数据，不读取或输出群聊原文、密钥，不向真实QQ群发测试消息，不重启运行中的服务，不推送/发布 GitHub 变更。最终静态检查结果由本轮交付汇总记录，不以本文预先认定通过。
