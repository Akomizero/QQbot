# 通用摘要：日期与关键说法核对

日期：2026-10-22（Asia/Shanghai）。适用于网页、主题及 Steam 公告摘要；保留原有长回复/合并转发与深色图文卡片。

## 已实现

- 先读取实际正文，直接读取成功时优先使用原页正文。只能依赖提取服务时说明读取边界，不把原页元数据与另一份正文拼接后冒称全文已核实。
- 发布日期、更新日期、检索时间分别显示；事件/上线/生效时间以正文片段标为线索，未来生效计划不当作未来发布日期或已发生事实。没有完整日期和时区时不补造。
- “今天、昨天、近期、最新”等按原请求的北京时间解释。明确使用“发布日期/发布时间/发表于/发布于/发表日期”指定完整日期或范围也可筛选；正文里的事件日期不会自动成为发布日期筛选条件。
- Steam 专用公告路径同样按日期范围筛选，指定的旧公告仍可总结但不能称为该时段新消息。范围内的结果不冒称整个官方频道当前最新；仅覆盖接口取得的有限公告。
- 收紧 JSON-LD 文章归属：保留 `?id=` 等内容参数，仅忽略已知跟踪参数；单个明确属于别页的 Article 不再作为当前文章日期。校验最大合法时区偏移。
- 网页摘要额外抽取最多 3 条关键事实说法，必须附实际正文中连续的原文片段。不是从群聊或成员资料生成搜索词。
- 最多两次补充搜索：一条具体关键说法、一条原文标题的更正/澄清线索；最多读取 3 个补充正文。其余关键说法只在本次实际取得的材料内对照，不承诺逐条穷尽全网。Serper 模式继续只经 Serper 搜索。
- 同一次最终回答生成摘要与逐条对照。程序校验说法编号、引用来源及连续原文片段；忽略未知来源、编造引文、原文自身作为补充证据，以及未能复核原页的提取文本。每条展示至多一个支持片段及一个不同说法片段。
- 输出区分“仅原文说法，未独立证实”“补充正文有支持，独立性未确认”“来源存在分歧”；来源网页身份、发布方自述、百科/社区内容有所标注。相同正文去重，多个转载不作为独立证实。程序不会因域名、名字匹配、多个站点或日期标注直接判定内容真实。
- 摘要及图文末尾附原来源、补充证据片段、真实链接、日期与读取限制。核对结构不完整时只返回原文片段与失败说明，不展示原始 JSON 或沿用旧核实状态。
- 直接粘贴的文字不进入补充搜索，仅总结提供内容并说明未外部核实。公开页面核对提取不携带本地群聊、成员印象或人设；搜索前过滤常见凭据、联系方式模式。
- 补充提取或搜索失败时保留原文归纳与限制，不把“没查到”当作“假”。最终模型调用与原文读取失败仍沿用既有故障提示/恢复流程。不发额外群进度消息。

## 管理入口与资源

聊天设置 → 读取网页并总结内容 → **日期与事实怎样核对**。沿用内容总结开关，无须额外配置密钥或开启另一项功能。正文对照会增加等待：最多一次额外的关键说法提取模型请求（30 秒、失败不补试）；最终摘要沿用原有模型重试预算。补充搜索继续使用当前搜索服务自身的有限重试。

不自动执行第三方 Skill。参考 [fact-check 工作流](https://github.com/petar-nauka/fact-check-skill/blob/main/SKILL.md) 的分析日期、事实/观点分离、证据登记与不确定性表达，实际读取和调用由本项目现有固定工具完成。

## 证据边界

本轮做修改文件语法检查、源码静态复核、服务重启和管理页只读查看；未新增/运行测试，未伪造 QQ 入站、发送群测试消息或额外发起真实摘要模型调用。真实摘要、支持/分歧语义判断、故障降级及 QQ 图文排版仍待实际使用观察。不能沿用其他功能此前的测试数量作为本次结果。

模型辅助语义对照可能误判，真实引文只证明该网页存在这段文字，不保证主张成立或来源独立。补充搜索并不覆盖全部事实，也不能保证发现所有谣言；出处、范围和不确定性随回复保留。现有角色纠正联网核对与外部事实候选审核继续生效，未把普通群友说法自动升级为已确认事实。
