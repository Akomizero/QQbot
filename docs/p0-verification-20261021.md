日期：2026-10-21（Asia/Shanghai）。本次管理员授权进行验证，并允许在另一个授权群发送少量标记测试消息及清理测试数据。未操作好友或加群申请。

## 结果

| 层次 | 结果 | 实际范围 |
| --- | --- | --- |
| 隔离验证 | 35/35 通过 | 源码副本，虚构知识/表情，模拟模型与 OneBot；覆盖真实 handleMessage 处理函数 |
| 真实模型 | 3/3 通过 | 普通文字、引用他人对象识别、单人教学候选提取；输入为虚构样例 |
| 真实 QQ 发出与读回 | 通过 | 在用户授权的另一个群发送 1 条明确标记的测试文字；读回核对同一消息、来源群、发送者和标记 |
| 清理 | 通过 | 撤回该条测试消息；模型提炼的测试词未写入正式知识库或表情偏好 |
| 管理页 | 可读取 | 查看模型诊断和知识候选数量/状态；没有确认、拒绝或编辑既有私人候选 |
| 公开副本复现 | 35/35 通过 | 独立安装锁定依赖后运行公开验证脚本，未使用正式密钥或 QQ |

首次隔离运行的两项失败由测试样本仅有一个标签导致；审核要求 2–6 个标签。补齐虚构样本后 35 项通过，没有为此放宽产品审核。首次真实 QQ 检查在发送前因 NapCat 调试接口多一层 data 包装而停止；修正验证脚本后只续跑 QQ 阶段，没有重复三次真实模型调用。

## 覆盖范围

- 模型：成功与关联号、瞬断恢复、关闭重试、401不重试、空答复后鉴权分类保留、空choices/空文字、拒绝、非法JSON、HTTP200错误载荷、未完成工具、截断、超时、诊断不存提示或密钥。
- 接话：@与引用作者分开、CQ引用、跨群引用拒绝、敏感引用遮蔽、引用他人不误认为追问、真实处理函数避免抢答@他人消息及传入结构化引用。
- 知识：带引用教学进入学习器、关联库存表情、拒绝不自动启用、修正不覆盖已确认知识、候选不进正式检索、群间隔离、跨进程学习状态。
