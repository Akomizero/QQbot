## 35项隔离覆盖

- 模型：正常完成、关联号、瞬断恢复、重试关闭、401不重试、空答复后鉴权错误保留、空choices、空文字恢复、关闭空答复补试、拒绝、非法JSON、HTTP200错误载荷、工具未完成、截断提示、超时、诊断脱敏。
- 对象：结构化发送者/@/引用作者、CQ解析、跨群引用拒绝、敏感引用遮蔽、引用他人不误判为追问。
- 表情：模拟审核建库、负面反馈临时规避、驳回恢复、具体图片分群禁用、并发修订冲突、最近3张去重、排队发送时复查。
- 入口和知识：真实处理函数不抢@他人消息、向模型注入引用、带引用教学到达学习器并关联库存表情、已拒绝不自动启用、修正不覆盖已确认知识、分群和候选检索排除、状态跨进程持久化、管理API认证和作用域。

## 实际边界

真实QQ检查覆盖bot发出、读回和撤回；没有使用第二个QQ账号真实发入消息。入站处理链和知识/偏好写入在源码副本里验证，不能据此声称所有群友输入都完成真实端到端验收。

单次模型检查通过不能证明此前ECONNRESET根因永久消失。未在本轮重新验收网页搜索、视频理解、所有GIF或角色识别准确率，也未做备份恢复演练。

## 复现

运行 `npm ci` 后执行 `npm run test:p0`。不需要任何真实密钥、QQ或NapCat。输出报告在被忽略的 `.local/p0-check-metadata.json`；测试副本在 `.local/p0-verification-*`。
