# 日常对话形成成员印象与自动维护

更新：2026-10-21（Asia/Shanghai）。本页替代早间“仅明确自述、每天12次共享额度”的成员积累说明。

## 后续维护更新

2026-10-22新增常用索引与可恢复归档，原过期清理改为归档保留，见[记忆维护说明](memory-maintenance-20261022.md)。下文过期删除及旧验证属于历史版本。

## 本次原因

两个授权群的成员开关均已启用，但没有成员印象；共享知识提炼次数都已达到当日12次。此前只接受少数明确自述表达，一般的AI对话不符合成员证据条件，普通自述也只会待管理员确认。

## 逐步形成

- 群友直接@bot、呼唤昵称或自然接话中的非敏感话题，可形成可见的初步观察，不需要说“记住”。单次有内容的对话亦可进入整理。
- 普通问题只产生“聊到某话题”的兴趣/互动观察，不自动认定喜欢该话题，不推断真人性格、身份、健康、财务或现实关系。
- 同一群、同一平台发送者、同一主题累计证据；消息与文字指纹去重。不同群、不同QQ和他人引用不合并；引用bot后的本人附言可以积累。
- 对话观察至少3条独立消息、2种不同文字，跨度至少5分钟才自动启用。普通自述至少2条独立消息、2种不同文字，跨度至少1分钟；明确“记住”的可靠自述仍可立即启用。初步观察可由管理员提前确认或拒绝。
- 成员积累不设每日调用次数额度；同群至少间隔5分钟合并整理，不逐句话调用。知识提炼仍保留自身每天12次限制，知识额度用完不会阻止有证据的成员对话整理；两者合适时合用同一次模型请求。

## 修正、淡出与清理

- 同主题证据更新同一条印象，避免不断添加重复档案。新的明确自述改变原有自动偏好时，采用更新说法并停用旧版本；不使用更早的迟到证据覆盖更新版本。
- 尚未得到支持的自动初步观察14天后清理；自动形成的对话观察60天没有支持时停用，120天后清理；已替代的自动旧版本保留30天后清理。维护按后续整理、读取或使用触发。
- 明确自述不会仅因没有新聊天而变成相反偏好。管理员确认的内容不会自动覆盖或过期清除；新分歧先待审核。拒绝、手动删除、暂停和“忘记我”的保护继续生效。
- 管理页卡片直接展示印象内容、初步/已形成/已修正/淡出状态、支持条数、最近更新时间和清理计数。每人20条、每群200人的存储边界保留。
