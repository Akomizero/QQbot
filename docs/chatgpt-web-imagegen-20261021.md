# ChatGPT 网页生图

## 已接入

- 管理页“聊天设置 → ChatGPT 网页生图”开关与只读连接/任务状态。
- 明确画图请求，例如 `肥鱼，画一张橙发少女的肖像`；群内也可 @bot 后输入 `/生图 描述`。普通“生成代码/生成文字”不触发生图。
- 本机已登录 Edge，经 web-access 的回环代理操作 ChatGPT 网页。独立标准聊天，不改用户已有对话，不读取/导出 Cookie 或密码。
- 全局串行处理，最多三项同时运行或排队；最多两张安全读取后的参考图。提示词经子进程标准输入传入，不放在命令行中。
- 成功后引用原消息发回原群/授权好友；开始处理、处理期间和发送前均检查开关和会话权限，群人设或成员清除状态变化后取消。
- 同一请求通过落盘任务编号去重。状态不确定时不自动重新生成或发送；新请求可重新作画。
- 仅使用网页生图。没有 Codex、内置 image_gen 或 OpenAI API 兜底；实际账户额度以 ChatGPT 页面和官方规则为准。
- 不自动收藏为表情或写入知识库；生成文件与本机任务回执在 `.local/chatgpt-images/`。

## 提示词细化

原先只在原话外包一层“请实际生成一张图片”，没有为短要求建立画面方案。现改为本地生成结构化绘图委托，并在同一次 ChatGPT 网页请求中要求先理解需求、细化画面后直接生成图片。

- 根据表情/贴纸、海报/版式、人物肖像、产品静物、场景画面分别补足与用途相关的细节。
- 细化主体身份、景别、姿态、视觉焦点、空间关系、光线、色彩与材质；不堆砌无关的质量词。
- 用户指定的画风、背景、动作、比例、尺寸与文字优先；完整提示词不应被重写为固定风格。
- 有参考图时要求实际查看并优先保持人物或物件的识别特征；只改变用户要求修改的部分。
- 说“不要扩写”或“严格按原提示词”时使用保留模式。
- 不额外调用 Codex 或其他模型 API 来扩写，不增加预处理的模型请求。网页内部如何理解与执行仍由 ChatGPT 决定，不能仅凭委托更详细保证画质提升。
- 回执只记录提示词版本、类别、模式和字符数，不增加原始需求或完整提示词的持久化。

此修改只进行了源码与语法检查，没有为比较效果额外生成图片或发送测试群消息。

## 本机连接前提

已安装 `chatgpt-web-imagegen`、`web-access`，Python 3.10+、Node.js 22+。Edge 中打开 `edge://inspect/#remote-debugging`，由用户开启允许远程调试并授权本机连接。

浏览器配置在 `%USERPROFILE%\.web-access\config.env`，`WEB_ACCESS_BROWSER=edge`。连接服务只监听 `127.0.0.1:3456`，首次运行：

```powershell
node "$env:USERPROFILE\.codex\skills\web-access\scripts\check-deps.mjs"
```

浏览器关闭、登录失效或连接授权被撤销会阻断生图。安装组件并不表示 browser 已连接；管理页显示实时状态。

## 原始组件与本机适配

网页生图脚本来自 [liangming99/chatgpt-web-imagegen](https://github.com/liangming99/chatgpt-web-imagegen)，MIT 许可证与适配脚本存放于 `tools/chatgpt-web-imagegen/`。本机适配：`POST /new`、每次独立聊天、等待输入框就绪、参考图上传、标准输入传提示词；只识别生成图片/助手图片，避免误取用户参考图。安装新版 skill 时，不应无意覆盖这些适配。

浏览器组件来自 [eze-is/web-access](https://github.com/eze-is/web-access)，仍需独立安装与授权。本项目备份包含适配后的生图脚本和本机图片任务；不复制 Edge 登录凭据。

## 本轮实际结果与限制

2026-10-21：已连接真实 Edge，确认 ChatGPT 输入框可用；按用户给定的参考图生成 Claude 全身肖像，取回 1024×1536 原图，约 2.01 MiB，人工查看画面后发到用户指定的授权群。OneBot 返回消息编号，并通过 `get_msg` 确认群、发送账号和图片段。

页面同时出现“图像生成失败”和可下载的完整生成图片。本轮依实际图片文件核验，不以提示文案推断成功；原图已人工确认。最初管理调试接口的 base64 发送未确认成功，查阅覆盖该时段的群历史未发现图片后，改用本机文件路径发送并读回确认。没有再次生图。

生产模块完成语法检查；以上网页生成、取图、指定群发送分阶段实测，没有伪造群成员消息来测试 inbound 触发。未额外运行自动化测试，也未强制造成登录失效/断线来验证故障分支。

## 电源状态

此电脑支持 S3 睡眠，真正睡眠或关机期间，本机代码无法运行。当前交流电自动睡眠已设为“从不”，显示器仍按原来的 30 分钟关闭；电池设置未改。原电源设置备份在 `%USERPROFILE%\.web-access\power-settings-before-20261021.json`。

自动睡眠被禁用并不阻止用户主动点“睡眠”、关机或断电。若要求电脑休眠时仍全天候服务，应将 bot、NapCat/QQ 和已授权的网页运行环境迁至另一台持续运行的机器。
