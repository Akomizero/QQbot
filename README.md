# 肥鱼 QQ 群聊机器人

自建 Node.js 服务，通过独立运行的 NapCatQQ / OneBot 11 反向 WebSocket 接入 QQ 群聊和好友私聊。提供本机 Web 管理页、分群人设、分群知识、图片和表情处理，以及可选的搜索与内容总结。

## 当前能力

| 功能 | 范围 |
| --- | --- |
| 聊天 | @、昵称呼唤、结合引用关系接话；按会话排队，实际回复至少间隔10秒 |
| 人设 | 每群独立昵称、人设和固定长期记忆；私聊单独处理 |
| 群聊参与 | 合并话轮后判断是否参与；无人回应时暂停主动发言 |
| 知识 | 本机关键词检索、分群积累、待确认/拒绝、来源指纹、修正候选 |
| 成员印象 | 按群号+QQ号积累明确自述；候选审核、修正、停用、删除、忘记与暂停 |
| 视觉 | JPG/PNG/WebP/GIF，GIF以首帧聊天；虚构角色辨认及已有参考匹配 |
| 表情 | 上传、显式赠送、自动收藏、用途与避免场景、内容审核、分群禁用与近期去重 |
| 搜索 | Tavily → Exa MCP → B站备用；模型可按需调用工具 |
| 总结 | 主题、公开网页、粘贴文字；来源与日期核对，文字转发或深色图文长图 |
| B站 | 元数据、可取得的字幕、可选本地语音转写和有限关键画面 |
| 运维 | 诊断号、有限重试、本机管理认证、Windows登录自启与异常恢复、校验备份 |

## 安装

需要 Node.js 20.9 或更高版本，以及单独安装并登录的 [NapCatQQ](https://github.com/NapNeko/NapCatQQ)。Windows运维脚本使用PowerShell。其他系统可直接运行Node服务。

~~~powershell
npm ci
Copy-Item .env.example .env
~~~

在本机编辑 `.env`，为 `ONEBOT_ACCESS_TOKEN` 填写新生成的32位以上随机令牌，并填写自己的模型及可选Tavily密钥。密钥仅留在服务端。

~~~powershell
npm start
~~~

默认管理页为 `http://127.0.0.1:3000`。首次打开时自行设置至少12字符的管理员密码。管理认证使用scrypt哈希和HttpOnly会话Cookie。

在NapCat WebUI新增WebSocket客户端：

- 地址：`ws://127.0.0.1:16700/onebot/v11/ws`
- 消息格式：array
- Token：与本机 `.env` 中令牌一致
- 图片读取：按当前NapCat版本开启 `enableLocalFile2Url`，使 `get_image` 返回Base64

在管理页完成：

1. “群与权限”填写自己的群号和允许私聊的好友号。公开版初始白名单为空。
2. “聊天设置 → 模型连接与回复参数”填写自己的OpenAI兼容Chat Completions接口地址和模型ID。公开版接口是占位地址，须先修改；预设模型ID仅是可编辑配置，不保证服务商提供。
3. 按需开启搜索、视觉、知识积累、视频理解与主动聊天；模型调用可能产生服务商费用。
4. “分群人设”编辑各群角色；“知识库”和“表情包”管理本机资料。

`npm run web` 仅启动管理页。`npm run dev` 使用Node watch模式。

## 管理和使用

- “知识库”先选群：单人解释可形成待确认候选，多人支持可自动启用。拒绝不会自动重新启用；对已确认资料的不同说法先形成修正候选。重启不恢复原始聊天缓冲，只保留学习状态、计数和提炼结果。
- “成员印象”先选群：群友明确说“记住，我喜欢……”可直接积累非敏感兴趣，普通自述待审核。修改后点“保存成员”。本群@bot说“忘记我”清除自己的印象并暂停；“继续记住我”恢复积累。
- “表情包”可配置本群逐图/关键词禁用。群友明确说“别发某表情”先临时避开15分钟，管理员确认后持续禁用；最近10分钟用过的3张也会避开。库存选图在实际发送前再次检查规则。
- GIF/图片上传每张最多20MiB，模型输入另行缩小；库最多50张、总量60MiB。自动收藏与手动上传的压缩策略不同。
- 复杂分析可要求详细讨论或图文版。摘要支持游戏以外的新闻、文章、教程等；无法核对“最新”或发布日期时会说明。
- 长回复可用QQ合并转发，图文排版失败时回退文字。客户端、服务商及公开站点可用性仍影响结果。

## 诊断与验证

在“聊天设置 → 模型连接与回复参数 → 查看最近诊断”查看错误类别、HTTP状态、耗时和关联号。诊断不保存正文、图片、接口地址或密钥。鉴权错误、拒绝、空响应、工具未完成和网络中断分别处理。普通回复的每个模型步骤在同一60秒预算内最多请求2次（首次加1次补试），空回复也共用额度；关闭补试则仅1次。工具后续步骤、角色辨认和后台学习是独立任务。视频材料已取得但模型回答失败时会单独说明。模型代理连接使用当前DNS解析的IPv4隧道并保留原域名证书验证；不保证外部网络永久稳定。

~~~powershell
npm run test:p0
~~~

该命令复制源码到忽略的 `.local/p0-verification-*` 目录，使用虚构资料、模拟模型和假OneBot，验证108项P0/P2、成员印象、模型连接与图片上下文行为；不发送QQ消息，不使用正式密钥，不更改正式知识库。报告写入 `.local/p0-check-metadata.json`。保留测试副本便于排查，可在关闭测试后自行删除。

## 视频与常驻（可选）

~~~powershell
powershell -File scripts/setup-video.ps1
powershell -File scripts/install-autostart.ps1
~~~

视频脚本需要Python 3.11+，安装faster-whisper并下载语音模型。Windows常驻脚本安装当前用户登录启动、崩溃恢复，并在运行时抑制自动系统睡眠。真实休眠、注销、关机时本机程序不能运行；NapCat也需自行保持在线。

~~~powershell
powershell -File scripts/stop-bridge.ps1
powershell -File scripts/backup-project.ps1
~~~

备份含本机密钥、认证、知识和表情等运行数据，只能私下保管；不应上传GitHub。备份逐文件校验SHA-256，恢复方式在ZIP内 `RESTORE.md`。公开源码包不能替代运行数据备份。

## 数据与限制

- 服务只绑定 `127.0.0.1`；管理页验证登录和Host/Origin。请勿把初始化页或管理接口转发到公网。
- `data/` 存配置、知识与偏好，`.local/` 存认证、表情、节流和诊断。除示例外均忽略，不随仓库发布。
- 开启模型、搜索或视觉后，相关输入会发送给你配置的服务；知识检索本身在本机运行，命中片段会提供给模型。
- 不含QQ登录会话、NapCat二进制、私人聊天记录、上传表情、服务端密钥、个人固定记忆或开发备份。
- 本项目不执行聊天传来的shell/Skill文件。检索和视频能力是应用内部实现。
- Exa备用搜索不保证严格国内来源；B站搜索只返回元数据，视频理解受字幕、时长和匿名访问限制。原生Google grounding尚未证实。
- 成员印象从部署后的新自述开始，不回填历史；完整角色参考管理页仍未实现。虚构角色识别不能保证覆盖新角色、二创或换装；不猜测真人身份。
- NapCat属于独立第三方接入，请参考其官方说明和许可证。此仓库不包含该项目代码或登录程序。

## 分条发图与连接恢复

所有授权群均支持：先发图片，3分钟内再@bot说‘如何评价’或‘这个图片’，会关联同一成员最近一次图片消息；正在与bot对话时也支持图片追问和45秒内纯图片跟进。引用同群图片可明确指定15分钟内的来源。GIF当前只看首帧。关联按群和发送者区分，按需读取原图，不持久保存聊天图片。详见[图片上下文](docs/image-context-20261021.md)。

模型支持独立的本机认证出口与备用节点、健康连接池复用、失败淘汰及连接诊断。重试成功走正常发送路径，历史诊断回放默认仅记录生成结果。最新108/108隔离回归通过；真实单条恢复回复已发出并回读确认。证据与限制见[专用出口与发送](docs/model-route-recovery-20261021.md)。
